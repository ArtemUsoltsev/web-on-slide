# Веб на слайді (web-on-slide)

Content add-in для PowerPoint: показує будь-яку HTTPS-сторінку на слайді. Один статичний сайт, без збірки й залежностей.

| Файл | Призначення |
| --- | --- |
| `manifest.xml` | Маніфест надбудови. Завантажується в «Інтегровані застосунки» або sideload. |
| `index.html`, `app.js` | Сторінка надбудови на слайді. |
| `config.js` | Списки дозволених/заборонених доменів і спільна перевірка адрес. |
| `dialog.html`, `dialog.js` | Перехідник для діалогу Office (режим «кнопка», сайти з X-Frame-Options). |
| `help.html` | Інструкція для доповідачів, на неї вказує `SupportUrl`. |
| `icon-32.png`, `icon-64.png` | Іконки з маніфесту. `icon-80.png` потрібна лише для AppSource. |

## Розгортання

1. Маніфест налаштований на пілотний хостинг `https://artemusoltsev.github.io/web-on-slide/` (публічний репозиторій `web-on-slide` з GitHub Pages, гілка main, корінь). Для іншого хостингу замініть адресу в `manifest.xml` (4 місця). Продуктив: хостинг під контролем організації.
2. Перевірте маніфест: `npx office-addin-manifest validate manifest.xml`.
3. Відкрийте `https://<ваш домен>/help.html` і `https://<ваш домен>/index.html` у браузері: перша має показати інструкцію, друга повідомлення «працює лише всередині PowerPoint».
4. Sideload для тесту, потім Microsoft 365 admin center → Integrated apps → Upload custom apps.

### Оновлення

- Будь-яка зміна `manifest.xml` вимагає підняти `<Version>`; централізоване розгортання доходить до користувачів до 24 годин.
- Зміни в `app.js`, `config.js`, `dialog.js` вимагають підняти параметр `?v=` у `index.html` і `dialog.html`, інакше Office віддасть кешовану копію.
- Якщо репозиторій на GitHub Pages: захист гілки, обов'язковий рев'ю, 2FA. Хто пише в гілку, той міняє код у всіх презентаціях одразу.

### Білий список доменів

У `config.js` заповніть `allowedOrigins` (саме origin: схема + хост, без шляху). Той самий список `app.js` додає в CSP `frame-src`, тому він обмежує і переходи всередині вбудованої сторінки, не лише першу адресу. `blockedOrigins` лише не дає вставити адресу; переходів усередині сторінки він не контролює.

## Що вирішено й що лишається перевірити на пілоті

Виправлення за аудитом від 2026-11-05 (версія 1.2.0.0):

- `Permissions` знижено до `Restricted`. Документація підтверджує Settings і `getActiveViewAsync`; `ActiveViewChanged` та діалог на цьому рівні **перевірити на пілоті**. Якщо не працюють, підняти до `ReadDocument`.
- `AllowSnapshot=false`: знімок сторінки не зберігається у .pptx. Наслідок: порожня рамка в Teams PowerPoint Live, при друці і без надбудови. Поставити `true` лише за рішенням служби безпеки.
- Єдина функція перевірки адрес у `config.js`: тільки https, без логіна/пароля, не власний домен надбудови, списки доменів, попередження про токени в запиті, автододавання `https://`.
- Захист від відсутнього office.js, відсутнього config.js і відкриття поза Office: зрозуміле повідомлення замість чорного екрана.
- `isSetSupported` для DialogApi/ActiveView; без діалогу режим «кнопка» вимкнено.
- Перевірка результату `saveAsync`; повідомлення, якщо зберегти не вдалося.
- Кнопка «Змінити» більше не скидає збережену адресу; є «Скасувати»; форма не блимає під час показу.
- Картка «Сторінка не відповідає» через 10 с без завантаження, з кнопкою «Відкрити у вікні».
- У PowerPoint для вебу діалог відкривається з `promptBeforeOpen`, щоб обійти блокувальник спливних вікон; при помилці картка з адресою для копіювання; коди 12007/12009 не викликають запасний шлях.
- CSP: `object-src 'none'`, `base-uri 'none'`, `form-action 'self'`, дозволені домени телеметрії Office; окремий CSP у `dialog.html`, скрипт винесено в `dialog.js`.
- Панель «Оновити / У вікні / Змінити» напівпрозора і займає лише місце під кнопками, щоб не перехоплювати кліки по сайту.
- Доступність: `role="alert"` для помилок, `title` iframe = домен сайту.
- `Override en-US` для назви й опису; `SupportUrl` веде на `help.html`.
- Без `catch {}` та інших конструкцій, яких немає в старих двигунах; код написаний на ES5 + `URL`.

Перевірити на пілоті (з коду не видно): діалог під час показу слайдів на кожній платформі; голосування Mentimeter у PowerPoint для вебу (сторонні cookie); проксі з автентифікацією зсередини мережі; чи пропускає проксі `appsforoffice.microsoft.com` і хостинг надбудови.
