# Веб на слайді (web-on-slide)

Надбудова вмісту (content add-in) для PowerPoint: показує живу HTTPS-сторінку прямо на слайді (голосування Mentimeter, гру, відео, будь-який сайт), а також має вбудовані інструменти тренера (таймери, випадковий вибір, рахунок команд тощо). Працює в PowerPoint для Windows, Mac і вебу з Microsoft 365.

Це статичний сайт: без власного сервера, бази даних, збирання, npm-залежностей, аналітики й реклами.

| Файл | Призначення |
| --- | --- |
| `manifest.xml` | Маніфест надбудови. Завантажується в Microsoft 365 admin center (Integrated apps) або в мережевий каталог надбудов |
| `index.html`, `app.js` | Сторінка надбудови, яку PowerPoint показує в блоці на слайді |

## Обмеження

Сторінка показується у вбудованому браузері Office: у PowerPoint для Windows це Edge WebView2 (Chromium), на Mac це Safari (WebKit), у PowerPoint для вебу це браузер користувача.

- Сайти, що забороняють вбудовування (`X-Frame-Options` або CSP `frame-ancestors`), у блоці не покажуться; для них є режим «У вікні».
- Адреси лише на `http://` не приймаються взагалі.
- Сторінкам, яким потрібен вхід в акаунт, у блоці можуть заважати обмеження сторонніх cookie; краще режим «У вікні».
- Під час друку, експорту в PDF і в Teams (PowerPoint Live) замість сайту буде порожня рамка.
- Кожен відвіданий у показі блок тримає окремий процес WebView2 (близько 120–130 МБ). До 10 блоків у презентації без проблем; 40+ краще розділити на кілька файлів. Деталі в [docs/security-review.md](docs/security-review.md#продуктивність-і-ресурси).

## Розробка й оновлення

- Після зміни `app.js`, `config.js`, `widgets.js`, `dialog.js` чи файлів таймера підніміть параметр `?v=` у `index.html`, `dialog.html` і `app.js` (`TIMER_URL`), інакше Office візьме стару копію з кешу.
- Після будь-якої зміни `manifest.xml` підніміть `<Version>`.
- Перевірка маніфесту: `npx office-addin-manifest validate manifest.xml`.
