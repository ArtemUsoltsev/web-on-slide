Web on Slide add-in

Shows a live web page (a poll, a game, any site) right on a PowerPoint slide. Works in PowerPoint for Windows, Mac and the web. Українською

How to insert

  1. Open a slide and choose Insert → Add-ins → My Add-ins → Web on Slide.
  2. Paste the page address and click Show on slide. The block can be moved and resized like a shape.
  3. Each slide can have its own address. Copying a slide copies its address too.

Which address to use

  • Only links meant for the audience. The address is saved in the presentation file as plain text, and anyone who gets the file can see it. Don't paste presenter or admin links or links with tokens.
  • YouTube, Vimeo, Google Docs/Sheets/Slides/Forms, Google Drive files, Miro, Figma, Canva: paste the normal address from your browser. The add-in turns it into the embeddable form (a hint appears under the field). The file must be viewable by link.

Options (“More options” on the form)

  • Session code. Put {code} in the address, e.g. https://www.menti.com/{code}. A “Session code” field appears, and a Code button on the block’s toolbar.
  • How to show: page on the slide, a button that opens a window (for sites that forbid embedding), or a QR code only.
  • QR code in the corner, show on click (a cover with your caption first), auto refresh (10 s – 5 min), autoplay video (YouTube, Vimeo, muted).
  • Zoom into a part of the page (×1.25–×3) with sliders to choose which part.
  • Tabs: up to three more pages in the same block, one per line as Name | address.
  • Text if the page doesn't open: shown instead of the standard message; without a network it appears at once.
  • Border and rounded corners; templates under the address field and your recent addresses (stored only on this computer).

Trainer tools

In Show, besides a web page you can choose:

  • Timer and Break until a time (e.g. back at 14:30, counted by the computer clock).
  • Timer PRO (all modes): the full trainer timer with countdown, intervals, stage program, speaker queue, chess clock and stopwatch, 15 indicators, 60+ themes (DTEK light by default), presets, sounds and scores. Set it up right in the block: the sliders button (or F) opens the settings, and changes are saved in that slide. The slide show shows only the dial; the controls appear when you move the mouse. Presets, audio clips and the logo stay on this computer.
  • Random picker as a list or a wheel of fortune (up to 40 names).
  • Team scores; tick Shared score so every block with the same teams shows the same points on all slides (kept on this computer for 12 hours after the last change or until Reset, not in the file).
  • Split into groups by number of groups or group size.
  • Show of hands vote: 2–6 options, the trainer adds the counted hands.
  • Quiz card: mark the correct option with *; answer timer and Show answer.
  • Agenda with stages: lines “Name | minutes”, moves to the next stage by itself.
  • Card deck: cases, questions or roles drawn without repeats.
  • Dice, coin, number.

Keys (click the block during the show): Space is the main action, Enter shows the quiz answer, 1–6 add a point or vote, Shift+digit subtracts, arrows switch agenda stages. Copy results puts groups, votes, scores or picks on the clipboard.

Also: join card (QR-only mode with a {code} address shows the short address and the code in big digits), My templates (save a configured block on this computer and reuse it; admins can add organization templates in config.js), and auto-switching tabs every 10 s – 1 min.

They work without internet; time, scores and picks start over with every slide show, except a shared team score.

Limitations

  • Sites that forbid embedding (Google search, banks, many corporate systems) won't show in the block: use “Button that opens a window”.
  • Only https:// addresses are accepted. Flash, Java applets and ActiveX don't work.
  • After you click inside the site, arrows and the clicker control the site, not the slides. Click outside the block to give control back to PowerPoint.
  • When you return to a slide the page reloads. Add-ins don't run in Teams “PowerPoint Live”; print and PDF export show an empty frame.

Security

The add-in stores only its own settings in the file, doesn't read slide content, has no server of its own and collects no data. See the privacy policy.
